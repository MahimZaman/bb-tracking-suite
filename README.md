# BioBalkan Tracking Core

Clean Meta Pixel + CAPI + GA4 tracking (multi-domain, consent-ready, WooCommerce events).

## Installation and use

Place the `bb-tracking-suite` directory in `wp-content/plugins/` and activate **BioBalkan Tracking Core** from the WordPress Plugins screen.

Configure tracking in WordPress before enabling events for a store. The plugin integrates Meta Pixel, the Conversions API, and Google Analytics 4.
